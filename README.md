# Rick & Morty Characters

Flutter приложение, отображающее персонажей вселенной «Рик и Морти» с возможностью пролистывания, поиска и сохранения избранных. Данные кешируются локально (Hive), поэтому список доступен офлайн; изображения обслуживаются `cached_network_image`, избранные персонажи и настройки темы сохраняются между запусками.

## Сборка и запуск

1. Установить Flutter и зависимости проекта:
   ```bash
   flutter pub get
   ```
2. Запустить локальные проверки (опционально):
   ```bash
   flutter analyze
   ```
3. Собирать и запустить приложение:
   ```bash
   flutter run
   ```
